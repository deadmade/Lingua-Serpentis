# v2 Lists (`lista`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a growable, statically-typed, value-semantics list type (`lista`) to Lingua Serpentis — the language's first parametric type.

**Architecture:** Extend the existing lexer → parser → checker → interpreter pipeline. `Type` becomes recursive (`Type::List(Box<Type>)`), which forces it from `Copy` to `Clone` — the single largest edit, done as an isolated refactor before any feature work. Lists are then built up one capability per task: literals, index-read, index-write, and the `longitudo`/`adde` built-ins. A new `Value::List(Vec<Value>)` inherits value semantics from the existing `Clone` model, so no `Rc`/`RefCell` is needed.

**Tech Stack:** Rust (2021 edition), workspace with crates `lingua-serpentis` (interpreter) and `latinitas` (Latin checker). Hand-written lexer/parser/checker/tree-walking interpreter. No third-party deps.

```rust
    /// Type a list literal against an optional expected list type. Element
    /// float literals adapt to the expected element type; an empty literal is
    /// legal only when the expected element type is known.
    fn resolve_list(&self, e: &mut Expr, expected: Option<Type>, line: usize) -> LResult<Type> {
        let elems = match e {
            Expr::ListLit(v) => v,
            _ => unreachable!("resolve_list called on non-list"),
        };
        let elem_expected = match &expected {
            Some(Type::List(inner)) => Some((**inner).clone()),
            _ => None,
        };
        if elems.is_empty() {
            return match elem_expected {
                Some(t) => Ok(Type::List(Box::new(t))),
                None => Err(LinguaError {
                    message: "typus elementorum seriei vacuae ignotus".into(), line }),
            };
        }
        let mut it = elems.iter_mut();
        let first = self.resolve_expr(it.next().unwrap(), elem_expected.clone(), line)?;
        for el in it {
            let want = elem_expected.clone().or_else(|| Some(first.clone()));
            let t = self.resolve_expr(el, want, line)?;
            if t != first {
                return Err(LinguaError {
                    message: format!("elementa seriei discrepant: '{}' et '{}'",
                        Self::type_name(&first), Self::type_name(&t)),
                    line,
                });
            }
        }
        Ok(Type::List(Box::new(first)))
    }
```
