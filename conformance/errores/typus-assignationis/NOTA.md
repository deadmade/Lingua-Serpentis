Assigning a `voc` to a variable already declared `ni`.

The message used to be byte-identical to the one for a mistyped *declaration*,
so the catalogue could not tell an assignment from a `ni x = "chorda";` — and
only the declaration form was ever provoked. `iam` ("already") is what
distinguishes them, and this case is what makes the assignment form
attributable (D-24).
